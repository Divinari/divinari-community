# Security Policy

## Scope

This policy covers public repositories under `https://github.com/Divinari` as well as responsible security or privacy vulnerability reports affecting Divinari services (`https://divinari.app`, `https://learn.divinari.app`).

## Reporting a Vulnerability

Please do **not** open public GitHub issues, Pull Requests, or Discussions for suspected security vulnerabilities, exposed credentials, PII, or copyright infringements.

- **Primary Channel:** Use **GitHub Private Vulnerability Reporting** (`Security` -> `Advisories` -> `Report a vulnerability`) on the affected Divinari repository.
- **Fallback Email:** Contact **support@divinari.app** with `[SECURITY]` in the subject line.

## Response Commitments

- Initial acknowledgment within 48 hours of receipt.
- Coordinated triage, remediation, and responsible disclosure timeline worked directly with the reporter prior to public advisory publication.
