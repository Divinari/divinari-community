# Student Capstone & Research Project Ideas

1. **Schema Validator Extensions:** Write deterministic Python checks for phoneme-to-IPA consistency or morphophonemic sandhi rules in `divinari-developer-resources`.
2. **Tagalog & Visayan Corpus Verification:** Conduct native-speaker auditing and example-sentence authoring to expand vetted `CC BY 4.0` starter lexicons.
3. **Stroke Order Pedagogical Audits:** Compare regional historical script sources to refine stroke sequences and stroke descriptions for public JSON schemas.

Students should work with faculty advisors under `CODE_OF_CONDUCT.md` and submit DCO-signed PRs via `CONTRIBUTING.md`.
