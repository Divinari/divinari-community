# Historical & Endangered Scripts Preservation

Divinari supports community documentation of historic and revitalized writing systems—including **Baybayin**, **Badlit**, **Kulitan**, **Kur-itan**, and global comparative scripts.

## Public Documentation Scope

- Clean-room Unicode codepoints, normalized `[0.0, 1.0]` directional stroke vectors, transliteration tables, and provenance notes belong in `divinari-language-resources` under `schemas/writing-system.schema.json`.
- Proprietary UI rendering code and interactive scoring engines remain private inside the Divinari app.
- Always cite credible paleographic or cultural sources when documenting regional script variations (such as *pamudpod* or *kudlit* conventions).
